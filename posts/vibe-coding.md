先说明：我不是程序员，只是个普通在校学生。JavaScript 还在入门中，Python 也只会写点脚本。

那这个站点是怎么做出来的？答案是：**99% 靠 AI**。

我用的是一个叫 TRAE 的 IDE，里面集成了 AI 编程助手。我只需要用自然语言描述我想要什么，它就会帮我写代码。从 HTML 结构到 CSS 样式，从 JS 逻辑到 DOS 终端的 TAB 补全，几乎都是它写的。

## 好处

- **速度快**：一个想法几分钟就能变成能跑的页面。
- **门槛低**：不懂的 API 和语法，AI 会帮你查。
- **能学到东西**：看 AI 写的代码，比看教程直观多了。

## 坏处

- **容易产生依赖**：离开 AI 可能就不会写了。
- **代码质量参差不齐**：有时候 AI 会写出很绕的逻辑。
- **调试还是得自己来**：AI 写的 bug，最后还是得自己改。

总的来说，Vibe Coding 对初学者很友好——先动手做出来，再慢慢学好。这个站点就是最好的证明。
